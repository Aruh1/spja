# Sistem Penjadwalan Tayang Anime (SPJA)

Sistem Penjadwalan Tayang Anime adalah aplikasi berbasis java (Netbeans 20) yang digunakan untuk mengelola jadwal tayang anime. Aplikasi ini memungkinkan pengguna untuk melihat jadwal tayang anime, menambah jadwal baru, dan keluar dari aplikasi.

## Fitur

- Melihat jadwal tayang anime
- Menambah jadwal baru
- Keluar dari aplikasi
